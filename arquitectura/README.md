# Plugin Arquitectura para IngeCAD

Esta carpeta es el plugin. Se instala copiándola en la carpeta de plugins de IngeCAD.

- Uso: `MANUAL.md`, en la raíz del ZIP.
- Organización del código: `docs/GUIA_DEL_CODIGO.md` (con su versión, en la raíz del ZIP).
- Cambios de cada versión: `CHANGELOG.md`.

El paso a IngeTrazo se hace con `EXPORTARBIM` y la extensión de `ingetrazo_ext/`. El puente
antiguo (EXPORTARIGZ, CONFIGIGZ, MURO3D, HUECO3D) se retiró en la v1.31.
